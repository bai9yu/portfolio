# 小白好白 | 白昱萱科研作品集

这是一个面向 GitHub Pages 的静态个人作品集网站，展示白昱萱的基本信息、教育背景、研究方向、论文专利、竞赛经历、项目经历、社会实践、奖项证明、科研简历和时间线。

## 内容结构

- `index.html`：作品集主页
- `styles.css`：页面样式
- `script.js`：奖项轮播脚本
- `assets/docs/`：科研简历 PDF
- `assets/papers/`：FedTeddi、CATS 与论文证明
- `assets/patents/`：专利证明材料
- `assets/competitions/`：互联网+ 与研电赛材料
- `assets/practice/`：社会实践报告
- `assets/awards/`：奖项证明
- `assets/thumbs/`：网页展示缩略图
