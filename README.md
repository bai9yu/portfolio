# 小白好白 · 研究与作品

白昱萱的个人作品集，发布于 https://bai9yu.github.io/portfolio/ 。

首页以研究星球、彩色项目卡片与论文卡片呈现研究定位；项目页聚焦研途喵、多智能体记忆与天枢，以功能导览、流程演示、图片轮播及可展开介绍呈现问题、设计与贡献；科研页区分会议论文、研究手稿和专利公开；荣誉页提供分类筛选与证书放大；关于我保留成长轨迹和简历入口。

站点使用静态 HTML、CSS 和 JavaScript，可直接部署至 GitHub Pages，无需模型密钥。作品集不读取私有科研工作台。实际工作台链接需要授权登录。

## 内容与媒体

- 首页提供可点击的研究星球；项目页使用功能导览与流程示意，天枢提供三张 PPT 图片的手动轮播。
- 天枢架构图为竞赛方案，演示画面属于软件仿真，不作为现场实测证明。
- Sylvas 已投稿 IEEE Communications Magazine，第二作者；展示论文 Fig. 3 工作流程图，不计为录用论文。
- 奖项证明沿用原有公开资料。列表缩略图使用 WebP，点击后加载原图。
- 论文实验数值保留方法、比较对象和适用设置，团队整体成果不计作个人成果。
- 原始论文、证书及旧媒体资源继续保留，历史版本通过 Git 提交记录查看。

## 交互与访问

研究星球支持切换项目；工作台支持切换功能导览；记忆流程支持逐步探索；项目介绍支持逐项展开；天枢图片支持循环切换与放大。荣誉可分类筛选，证书与论文架构图可放大，并使用 Esc 关闭。页面支持键盘访问与减少动态效果。

直接打开 index.html，或使用静态文件服务器即可预览，无需构建。

## 全站样式

五个主要页面统一使用 site.css。内页共享标题区、圆形视觉、导航、内容卡片、按钮、页脚与响应式规则。旧 timeline.html 跳转至 about.html#journey，competitions.html 跳转至 awards.html；不再维护重复页面。
